    How to merge PDF files

    1. Choose your PDF files, or drag them from a folder onto the box. Each file shows its page count as soon as it is read.
    2. Put the files in the order you want. The first file's pages come first. Drag a row to move it, or use the up and down arrows, which also work with a keyboard and on phones.
    3. Press Merge PDFs. The joined file downloads as merged.pdf. Open it once and flick through to check the order before you send it.

    What merging keeps, and what it does not

    Every page is copied as it is: the text, the images, the fonts and the page size. Text stays searchable and selectable, and pages are not compressed again, so a scanned document looks exactly as sharp as before. Files with different page sizes can be joined, and each page keeps its own size, so an A4 letter and a US Letter form can sit in the same PDF.

    A few things belong to a whole document rather than to its pages. Bookmarks and the outline panel of the original files are not carried across. Form fields filled in a PDF reader and links that jump to another page may stop working in the merged file. If you need those, keep the original files alongside the merged copy.

    Password-protected and damaged files

    A PDF with a password to open it, or with copying blocked, is encrypted, and its pages cannot be copied into another file without unlocking it first. The page tells you which file is locked instead of making a broken PDF. To unlock a file you are allowed to open, open it with its password in any PDF reader or browser, choose Print, pick Save as PDF as the printer, and merge the new copy. Files that are damaged, cut short by an interrupted download, or not really PDFs are named in the same way, so you know exactly which one to replace.

    Common reasons to merge

    • Sending one file for an application: a form, an ID proof, an address proof and a photo page, in the order the office asks for.
    • Joining monthly bank or card statements into one file for a loan, a visa or a tax return.
    • Putting scanned pages that came out as separate files back into one document.
    • Combining a report with its appendix, or a quote with its terms, before emailing them.

    Turning photos of documents into a PDF first? Use JPG to PDF, then merge the result with your other files here.

    Private by design

    The files are read and joined on this page by pdf-lib, an open-source library that runs in your browser. Nothing is uploaded, nothing is stored, and there is no account, so it is safe for statements, contracts and identity documents. Once the page has loaded, merging works with the internet switched off.

    Questions people ask

    Are my PDFs uploaded anywhere?

    No. The files are read and joined by your browser with pdf-lib, an open-source PDF library that runs on this page. Nothing is sent to a server, so bank statements, contracts and ID documents stay on your device.

    Is there a limit on files or pages?

    There is no set limit and no watermark. The only limit is your device's memory, because the files are held in the browser while they are joined. Most phones and laptops handle dozens of ordinary PDFs without trouble.

    Why does it say my PDF is password protected?

    The file is encrypted, and its pages cannot be copied without the password. Open it in a PDF reader with the password, then use Print and choose Save as PDF, which makes an unlocked copy. Merge that copy here.

    Do links, bookmarks and form fields survive?

    The pages, text, images and page sizes are copied exactly, and the text stays searchable. Bookmarks from the original files are not carried over, and filled form fields and links that point to other pages may not work in the merged file. Check the result if those matter.

    Can I merge only some pages of a file?

    This tool joins whole files. To keep only certain pages, open the PDF in a reader, print those pages with Save as PDF, and merge the smaller file here.

    Will the merged file be larger than the originals?

    It is usually close to the size of the files added together. The pages are not compressed again, so their quality does not change.
