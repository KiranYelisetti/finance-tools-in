What is inside a QR code

A QR code is a grid of black and white squares that stores text. The three large squares in the corners tell the camera where the code is and which way up it is. The rest of the grid holds the text itself plus extra repair data, so a phone can still read a code that is a little blurred, scratched or covered. That repair data is the error correction level. The QR standard defines four levels, and they can restore roughly 7, 15, 25 and 30 percent of a damaged code. More repair data means more squares, so a high level makes the pattern denser and harder to read when it is printed small.

The codes made on this page are static. The link or login sits inside the pattern itself, so the code keeps working forever and nobody can count who scans it. Paid QR services often sell dynamic codes instead, which point to their own short link first. Those can be edited and tracked, but they stop working if the service closes or the subscription ends.

QR codes for UPI payments

A UPI code holds a payment link that every UPI app understands. It names the UPI ID that receives the money, the name the payer sees and, if you add one, the amount. When someone scans it with a UPI app, a payment screen opens with those details filled in. They still confirm the payment with their own UPI PIN, so the code cannot take money by itself. Leave the amount empty for a code you print once for a shop counter, and the payer types the amount each time. Add an amount for a one-off bill, such as a share of a dinner or a fixed fee. Banks and UPI apps set their own daily and per-payment limits, so a very large amount may need to be split.

Before you print a payment code, scan it with a UPI app yourself and check that the name it shows is yours. A code is only as trustworthy as the person who made it, which is also why, when paying a stranger, you should always read the name your app shows before entering your PIN.

Wi-Fi codes for guests

A Wi-Fi code saves your guests from typing a long password. Recent Android phones and iPhones read it straight from the camera app and offer to join the network. Type the network name exactly as it appears on a phone, including capital letters and spaces, and choose the security type your router uses, which for nearly every router made in the last decade is WPA2 or WPA3. Anyone who can see the code can join, so keep it inside the house or office and make a new code whenever you change the password.

Printing a code that scans

  • Keep the code dark on a light background. Light codes on dark backgrounds and coloured codes fail on many phones.
  • Leave the white border around the code. Cameras need that quiet zone to find the edges.
  • A common rule of thumb is to print the code at least a tenth as wide as the distance people will scan it from, so a code read from a metre away should be around 10 cm across.
  • Shorter content makes a simpler pattern that scans more easily. A short link is better than a long one with tracking parameters.
  • Use SVG for print. It stays sharp at any size, while a small PNG blown up for a poster turns blurry.

Your data stays on your device

The code is drawn by your browser from what you type. Nothing is uploaded, and Wi-Fi passwords, UPI IDs and phone numbers are not saved after you close the page. That also means the code works with no account and no limit on how many you make.

Questions people ask

Do these QR codes expire?

No. The link, text or login is stored inside the pattern itself, so the code works for as long as the printed copy can be scanned. Some sites sell dynamic codes that point to their own short link and stop working when you stop paying. The codes made here do not go through any server.

Which error correction level should I pick?

Medium suits most uses. Higher levels add more spare data, so a code that is scratched, partly covered or printed with a logo on top can still be read, but the pattern gets denser. Low is fine for a code shown on a screen. High is the choice for a code printed outdoors or on packaging.

How does a UPI QR code work?

It holds a UPI payment link with your UPI ID, your name and, if you enter one, an amount. Any UPI app that scans it opens a payment screen with those details filled in. The payer still checks the name and confirms with their UPI PIN. This page only writes the link into a picture and never handles money.

Can a Wi-Fi QR code connect a phone without typing the password?

Yes. The camera apps on recent Android phones and iPhones read the Wi-Fi format and offer to join the network. Anyone who can see the code can also join, so print it where only your guests will see it, and make a new code if you change the password.

PNG or SVG?

PNG is a picture of fixed size that works everywhere, from WhatsApp to a Word file. SVG is a drawing that stays sharp at any size, so use it for posters, banners and anything sent to a printer.

Is anything I type sent to a server?

No. The code is drawn by your browser from what you type. Wi-Fi passwords, UPI IDs and phone numbers stay on your device and are not saved after you close the page.
